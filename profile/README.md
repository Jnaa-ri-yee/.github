## 📖 Sobre Nosotros

**Jña'a Ri Y'ë'ë** (del mazahua: *Jña'a* = hablar, *Ri* = modo indicativo, *Y'ë'ë* = mano) es un equipo de estudiantes universitarios de Ingeniería en Sistemas Computacionales y Mecatrónica, unidos por la convicción de que la tecnología puede y debe ser una herramienta de transformación social.

Elegimos este nombre porque refleja nuestras raíces mazahuas, representa el intercambio bidireccional de conocimiento y honra las lenguas originarias de México.

Nacimos en **octubre-noviembre de 2025** cuando un grupo de estudiantes identificó la necesidad de crear tecnología con propósito social. Lo que comenzó como una idea entre conversaciones se transformó en un proyecto colaborativo que busca hacer la diferencia.

## 🚀 Proyectos

### Sistema de Reconocimiento de LSM
**Estado**: 🚧 En Desarrollo Activo

Nuestro proyecto insignia busca romper barreras de comunicación mediante el reconocimiento de **Lengua de Señas Mexicana** usando visión por computadora e inteligencia artificial.

| Componente | Descripción |
|---|---|
| 🌐 Sitio Web | Plataforma de difusión y colaboración |
| 📱 App Móvil | Reconocimiento en tiempo real (multiplataforma) |
| 🤖 Modelos de IA | Sistema de reconocimiento con ML/DL |
| 💾 Backend | Infraestructura sobre Raspberry Pi 5 |

**Repositorios:** [Demo] · [Web] · [App] · [Server]

### Proyectos de Investigación
**Estado**: 🔬 En Planificación

- Herramientas de accesibilidad
- Automatización y optimización de procesos
- Análisis de datos para impacto social
